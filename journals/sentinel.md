## 2025-06-14 - Secure Connectivity
**Vulnerability:** Use of insecure HTTP for connectivity checks can be exploited for man-in-the-middle attacks during system installation.
**Learning:** Calamares internetCheckUrl defaults to HTTP if not explicitly hardened.
**Prevention:** Always use HTTPS (e.g., https://www.google.com) for connectivity verification URLs in installer configurations.
