# Contributing to KibaTV

Thank you for your interest in contributing to KibaTV! We welcome contributions from the community to help make this distribution faster and more efficient.

## Getting Started

1. Fork the repository.
2. Create a new branch for your feature or bug fix.
3. Ensure your changes follow our coding standards.
4. Submit a pull request.

## Repository Standards

- **Performance**: Every millisecond counts. Strive for efficient code.
- **Security**: Avoid dangerous commands like `eval` in production scripts.
- **Style**: Follow conventional commit formats.

We appreciate your help!
