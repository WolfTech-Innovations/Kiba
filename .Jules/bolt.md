## 2025-06-20 - [Bash Built-in Optimization for Date Formatting]
**Learning:** Using `printf -v vars "%(%d %H %y %m)T" -1` and Bash parameter expansion `${var:offset:length}` avoids multiple sub-process calls to `date`, `echo`, `cut`, and `sed`, which is significantly more efficient in high-frequency automation scripts.
**Action:** Prioritize Bash built-ins for string manipulation and date formatting in performance-critical scripts.
