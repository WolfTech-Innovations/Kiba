# Palette Journal

## 2025-05-15 - [KibaTV UX Standards]

**Learning:** QML configuration files and splash screens must use double-slash (`//`) for comments; hash (`#`) characters cause syntax errors. Standard window dimensions for Zenity menus on TV interfaces are strictly `--width=450 --height=500`. Informational Zenity calls in discovery loops must be backgrounded to remain responsive. Use the desktop monitor emoji (🖥️) for terminal shortcuts instead of the laptop emoji (💻).

**Action:** Always audit QML for `#` comments. Use standard Zenity dimensions and backgrounding for system menus. Use 🖥️ for terminal iconography.
