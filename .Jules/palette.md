# Palette Journal

## 2024-05-24 - [Accessible Zenity Menus]
**Learning:** Zenity list dialogs on KibaOS require specific configuration for discoverability and accessibility. Surfacing shortcuts as productivity tips improves UX and reduces cognitive load by making system functions immediately apparent to new users.
**Action:** When adding new global keyboard shortcuts, always include a corresponding "Productivity tip" in the `kiba-welcome` menu to ensure immediate awareness and usage.
