## Free and Open Source Software (FOSS) Projects

We acknowledge the many FOSS projects that KibaOS integrates and builds upon, including but not limited to:

### Base System
- **Arch Linux Project**: For the robust and rolling-release base system
- **Systemd**: For reliable init and service management

### Desktop Environment
- **Cutefish OS**: For the modern, Qt-based desktop environment
- **KDE Community**: For Plasma components and KWin window manager

### Visual Design
- **Dracula Theme**: For the iconic color palette that defines KibaOS's aesthetic
- **Ant-Dark Theme**: Base theme customized for KibaOS
- **Kora Icons**: For the colorful, modern icon set
- **Vimix Cursors**: For the sleek cursor theme

### Kernel & Performance
- **CachyOS**: For the performance-optimized kernel with BORE scheduler
- **UPX Team**: For the Ultimate Packer for eXecutables used in binary compression

### Applications
- **Bazaar (KibaStore)**: For the lightweight Flatpak store
- **Starship**: For the cross-shell prompt
- **Ungoogled Chromium**: For the privacy-focused browser

### Build System
- **Docker**: For containerized build environments
- **GitHub Actions**: For CI/CD automation
- **live-build**: For ISO generation infrastructure

### Modern CLI Tools
- **eza**: Modern `ls` replacement
- **bat**: Syntax-highlighting `cat`
- **ripgrep**: Fast search tool
- **fd-find**: User-friendly `find` alternative
- **btop**: Interactive resource monitor
- **fastfetch**: System information tool
- **tealdeer**: `tldr` implementation
